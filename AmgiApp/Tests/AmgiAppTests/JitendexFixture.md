# Jitendex scan fixture

`jitendex-scan-subset.zip` contains only the three original 先/先生 records from
`term_bank_35.json`, plus the original index and styles, from Jitendex.org
2026-08-11 (revision 2026.08.11.0). Other entries were removed; record contents
were not changed. This is a subset, not a complete dictionary.

Source: https://github.com/stephenmk/stephenmk.github.io/releases/download/2026.08.11.0/jitendex-yomitan.zip
